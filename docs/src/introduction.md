# plane-cli

plane-cli is a command-line client and terminal UI for self-hosted [Plane](https://plane.so/). It covers projects, work items, cycles, modules, labels, states, intake, members and invitations. Every command has a stable `--json` mode, so scripts and AI agents can use it safely.

> plane-cli is an unofficial, community-built command-line client for the Plane project tracker. It is not affiliated with, sponsored by, or endorsed by Plane Software, Inc. "Plane" is a trademark of its owner and is used only to describe what this tool works with.

Start with [Install](install.md) and the [Quick start](quick-start.md). If you are wiring up an agent, read [JSON output and exit codes](agent-contract.md) and [Agents and `--as`](agent-identity.md).
